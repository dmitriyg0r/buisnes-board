# Проверки движка диаграмм

## BPMN-адаптер

Запустите `npm run dev`, затем откройте в браузере `/tests/bpmn.html` на адресе Vite. Страница запускает проверки в настоящем браузере: работа с DOM/XML, создание, изменение и удаление элементов и потоков, совместимость с существующим парсером, отказ от записи неподдерживаемых и повреждённых моделей. В конце отображается число ошибок.

Дополнительные проверки: `/tests/bpmn-events.html` — определения событий; `/tests/bpmn-data.html` — хранилища, ассоциации данных и сохранность импортированных элементов. `/tests/editor.html` — интерактивный стенд редактора с тестовой моделью, без записи в базу данных. `/tests/edge-edit.html` — браузерная регрессия редактирования маршрутов, клавиатуры и истории; события перетаскивания моделируются программно. `/tests/resize-corners.html` — изменение размера с четырёх углов и отмена с клавиатуры. `/tests/connection-ports.html` — наведение и число точек связи.

Эти проверки не заменяют браузерные сценарии интерфейса, проверку реальных файлов или проверку соответствия сохранённого XML схеме BPMN 2.0.2. Для проверки XSD используйте опубликованные OMG файлы `BPMN20.xsd`, `Semantic.xsd`, `BPMNDI.xsd`, `DC.xsd` и `DI.xsd` в одном каталоге и команду `xmllint --noout --schema BPMN20.xsd файл.bpmn`.

Маршрутизация связей: `/tests/routing-regression.html` — обход объектов и перемещение; `/tests/edge-constraints.html` — ограничения ручного маршрута; `/tests/connection-magnet.html` — привязки, предпросмотр и история с синтетическими событиями. Геометрию можно проверить командой `node --experimental-strip-types tests/orthogonal-routing.ts`.

Управление редактором: `/tests/inline-label.html` — ввод в текстовом блоке; `/tests/selection-editor.html` — групповое выделение, перемещение и панорамирование с синтетическими pointer-событиями.
