# buisnes board — правила для Claude Code

Проект разрабатывает команда, часть кода пишется через Claude Code. Отвечай по-русски, комментарии в коде и тексты интерфейса тоже по-русски.

## Стек и структура
- `src/` — фронтенд: React 18 + TypeScript (strict) + Vite. Нет роутера и стейт-менеджера: состояние в хуках (`useModel`, `useIssues`, `useSettings`), запросы в `api.ts`, синхронизация с сервером в `sync.ts`.
- `backend/` — Rust, axum + sqlx, PostgreSQL. Роуты в `backend/src/routes/`, авторизация `auth.rs`, шифрование ключей сервисов `integrations.rs`.
- `backend/migrations/` — SQL-миграции sqlx, применяются при старте бэкенда.
- Vite проксирует `/api` на `127.0.0.1:8080`.

## Команды
- `npm run dev:all` — запустить всё (БД в Docker + бэкенд + фронтенд).
- `npm run check` — проверка типов и `cargo check`. **Запускай после изменений и перед тем как сказать «готово».**
- `npm run build` — сборка фронтенда.

## Правила
- Миграции: только новые файлы `NNNN_описание.sql` по порядку. Существующие НЕ редактировать и не удалять.
- Не коммитить `backend/.env`, `.pgdata`, `node_modules`, `dist`, `target`. Новые env-переменные — в `backend/.env.example`.
- Секреты (API-ключи пользователей) никогда не возвращать в ответах API и не логировать.
- Не добавлять новые зависимости без необходимости; спроси, если нужна тяжёлая.
- Меняй минимально нужное, не переписывай соседний код «заодно».
- Работа идёт в ветках. Агентам разрешено пушить в `main` (напрямую или через Pull Request), но только устранив все конфликты со свежим `main` и пройдя проверки; без `--force`. Подробности: `.claude/skills/git-workflow/SKILL.md`.
- После UI-изменений проверь в браузере (`npm run dev:all`), а не только типами.

## Объём функциональных проверок

Проверяй только изменённые функции и непосредственно затронутые сценарии по чеклисту в `AGENTS.md`. Не запускай проверки HTML, ИИ и других подсистем для несвязанных правок дерева, меню или значков. Общие обязательные проверки кода выполняются отдельно; для изменений только документации или инструкций достаточно проверки diff.
